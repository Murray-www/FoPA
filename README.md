# CyberCheck — конструктор чек-листов по кибергигиене

Учебный проект по дисциплине «Основы проектной деятельности» (кейс 10).

## Что внутри

- **`index.html`** — работающий прототип (без сервера, открывается двойным кликом):
  - вкладка **«Конструктор»** — no-code редактор: drag-and-drop блоков (текст, картинка, вопрос с вариантами), сохранение и публикация;
  - вкладка **«Пройти квиз»** — прохождение чек-листа как квиза с результатом и сертификатом;
  - вкладка **«JSON-схема»** — живая структура хранения и описание схемы.
- **`Отчёт_CyberCheck.docx`** — итоговый отчёт по ГОСТ.
- **`Презентация_для_защиты.pptx`** — презентация для защиты.
- **`Роли/`** — артефакты четырёх ролей (менеджер, аналитик+дизайнер, архитектор, разработчик+техписатель).
- **`screenshots/`** — скриншоты прототипа.

## Как запустить

1. Дважды кликните по `index.html` — откроется в браузере.
2. Ничего устанавливать не нужно: работает офлайн.

## Быстрая проверка

1. На вкладке «Конструктор» перетащите блок «Вопрос» на холст, введите вопрос и варианты, отметьте правильный ответ.
2. Вставьте в текстовый блок `<img src=x onerror=alert(1)>` — увидите, что он выводится как обычный текст (защита от XSS).
3. Нажмите «Опубликовать», перейдите на «Пройти квиз», ответьте на вопросы и получите сертификат.
4. На вкладке «JSON-схема» посмотрите структуру хранения.

## Примечание

Данные хранятся в `localStorage` браузера — это упрощение прототипа. В промышленной версии структура хранится на сервере в БД, а пользовательский ввод дополнительно очищается серверной библиотекой (например, DOMPurify).
